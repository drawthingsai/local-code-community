# Route: embedded-captions

- **Input:** Existing footage and supplied word or phrase timing data. It is an actual media file, not a URL or creative brief.
- **Output:** The same footage, untouched, with a foreground caption layer. Any length.
- **Triggers:** "add captions", "add subtitles".

## Interview

- **Must-haves:** which clip and timed text (the input files).
- **Run-shape:** neither — the footage is untouched; there is no storyboard to review.
