# Production loop — from an approved plan to a delivered video

The stages between a plan the user has agreed to and a video in their hands, written as **dependencies, not numbered steps**: order between independent stages is free — assets can be generated while frames build — order inside a dependency chain is not. Nothing in this file addresses the user: every user-facing pause lives in `review-loop.md`, and this file only marks where those passes attach. Some routes bring their own spine (a beat grid, existing footage) — the stages compose around it. A stage whose need is absent simply doesn't run: no narration, no audio stage; a single scene, no transitions. An edit request enters at the artifact it touches and re-runs verify.

| Stage               | Needs                                                                                                                                              | Produces                                                                                                                                                                                                       | Where the capability lives                                                                                                                    |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **Assets** | the approved plan | supplied or generated project-local assets | [hyperframes-cli](../guides/hyperframes-cli/GUIDE.md) → Generate media |
| **Audio** | supplied narration, music, and timing data | placed audio clips | [hyperframes-core](../guides/hyperframes-core/GUIDE.md) → `references/variables-and-media.md` |
| **Frames**          | design spec + the plan (+ a confirmed sketch cell in `storyboard.html` when one exists — dress that layout, never redraw it: `review-loop.md` § 3) | each scene at `compositions/frames/NN-*.html`, marked `animated` in the storyboard as it lands                                                                                                                 | `frame.md` + `hyperframes-animation` blueprints / rules (+ the genre lens, menu § Genre lenses) |
| **Duration sync**   | word timings + frames                                                                                                                              | scene durations trued to real voice length — real duration wins, silent scenes keep estimates, synced values are never hand-edited                                                                             | apply the supplied timing data                                       |
| **Assembly**        | frames                                                                                                                                             | the index composition — scenes as sub-compositions on tracks                                                                                                                                                   | `sub-compositions.md` + `tracks-and-clips.md`                                                         |
| **Transitions**     | the assembled index                                                                                                                                | scene handoffs injected                                                                                                                                                                                        | `../guides/hyperframes-animation/transitions/overview.md` → `catalog.md`                                           |
| **Captions** | supplied timings + the index | the caption track | [embedded-captions](../guides/embedded-captions/GUIDE.md) |
| **Verify**          | the index (+ captions / transitions when present)                                                                                                  | `hyperframes lint` and `hyperframes check` **passing**; a contact-sheet glance (`snapshot --at <frame-midpoints>`)                                                                                     | `hyperframes-cli`                                                                                                                             |
| **Deliver** | verify passing | the final-look pause → on approval prepare the [compiled export page](../guides/hyperframes-cli/references/preview-render.md#render), then `html2video .hyperframes-export.htm --output renders/video.mp4` | final approval: `review-loop.md` § 4; export: [hyperframes-cli](../guides/hyperframes-cli/GUIDE.md) |

The Frames stage follows the plan's citations: a scene planned on a blueprint or on named rules is built by reading that recipe's body (`../guides/hyperframes-animation/blueprints/<id>.md`, `rules/<id>.md`) before its motion is written — names come from the indexes, never invented, and a scene the plan left uncited gets its citation at build time, not improvised motion.

Two attach points carry the user's voice into this loop: the plan that starts it was approved at `review-loop.md` § 1 (collaborative) or posted as a heads-up (autonomous), and nothing renders before the § 4 final look. Everything between those two is yours to schedule.
