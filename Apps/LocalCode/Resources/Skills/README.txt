Built-in skills are bundled as subdirectories containing SKILL.md files.

Keep operational skill instructions product-neutral. Use "bundled Python runtime" or "bundled Node.js runtime" for execution, "current environment" for capabilities and constraints, "assistant" for identity, and "selected project" for file scope. Preserve exact tool names, commands, package versions, and virtual paths; neutral wording does not imply an unrestricted host environment. The product-introduction skill is an exception: preserve its product identity and wording.
